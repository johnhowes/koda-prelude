# Prelude

Design (and later build) an application with an agent. Pick a folder, chat with
an agent, watch the design appear. Built with [Koda](https://koda.johnhowes.workers.dev).

```
npm install
npm start        # http://localhost:4200
npm test
```

The desktop app (Windows, needs Rust): `npm run build:shell`, then run
`dist-shell/Prelude.exe` while `npm start` is running.

See `docs/plan.md` for the model, the ground rules and the steps.
