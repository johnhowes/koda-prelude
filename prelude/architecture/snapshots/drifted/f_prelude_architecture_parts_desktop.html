Desktop app

Its own process

A window on the server, built with Tauri. It adds a native folder picker and real pop-out windows, and starts the server when none answers.

Its job

Responsible for

  • Finding or starting the server, and stopping the one it started on quit
  • The folder picker, pop-out windows and Open in browser, for the server’s own pages only
  • Remembering each window’s size and position

Not its job

  • Anything a page can’t also do in a browser
  • Holding state: it shows the server’s pages
