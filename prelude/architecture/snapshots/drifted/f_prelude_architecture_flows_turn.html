A turn

From the person’s message to the check that follows the agent’s answer.

Steps

Step Part What happens
1 Routes The message is posted from the composer, from Prelude’s own origin.
2 Turns If the design has a turn running, the message waits; otherwise this turn starts.
3 Agent runner Runs the Claude CLI in the design’s worktree, with the kind’s prompt, the findings from the last check, and its permissions.
4 Live channels Each streamed event goes to the session’s windows as it’s written.
5 Project files Finished messages are appended to the transcript.
6 Branches When the turn ends, the files it emptied are deleted and the turn is committed.
7 Design host Renders every route in every state, and compares the pages with the approved screens.
8 Turns Pages that don’t render are kept for the agent’s next message; the next waiting message starts.

Decisions behind it

  • Every design works on its own branch, in a worktree D-v6t
  • The agent uses ordinary file tools, not domain tools D-j2s
